# 投研复盘工作流（investment-research）

## 描述
规范 TSP 语境下的投资研究工作流：研究不脱离平台已有口径（情绪周期/主线/异动/财务/AI 复盘），输出结论先行、口径清晰、来源可核验、星级化、带置信度与免责声明的报告。本技能只规范"怎么做研究"，不改变平台数据与算法。

## 使用场景
- 盘后/盘中复盘或研究任务（大盘、板块轮动、个股、财报）。
- 产出 Markdown 研究笔记/复盘报告/个股研究文档。
- 需要按统一模板分析市场情绪、主线、异动或财务质量。

## 指令

1. **确定任务与口径**：明确研究主题与区间（交易日/自然日？标的池？指标口径？），避免混用交易日与自然日、复权价与原始价、小数制与百分制。可对照 `docs/` 中对应领域文档（market-phase / features / strategy / mining 等）确认平台术语口径。

2. **对照平台已有研究能力**（研究"为什么/口径是什么"时引用，不虚构运行结果）：
   - 市场环境：情绪周期阶段（连板梯队驱动 + 2 日确认）与概念/行业主线排名 → `docs/market-phase.md`。
   - 异动：竞价/盘中/偏移三类口径（含交易所偏离值规则）→ 项目"异动监控"。
   - 财务：多源并集 + 公告日 PIT（公告前空值），财报/季报解读以官方披露为准。
   - AI 复盘/个股分析/财务解读为平台功能入口；其生成结论若被引用，标注"平台 AI 生成，需人工复核"。
   - 回测/挖掘结论遵守平台口径（T+1/费用/滑点/防未来函数），并注明"回测不代表未来收益"。

3. **信息收集**：优先一手来源（官方公告、定期报告、交易所、数据源原始口径）；二手资料（研报/自媒体）标注"转引"。能用已启用技能/工具核验真实来源 URL 时优先核验。

4. **分析与产出**：
   - 结论先行；每段给出证据与来源；区分事实、推断与主观。
   - 需要评价维度打分的，采用 1-5 星（★☆☆☆☆ 到 ★★★★★），并在文档中说明每项评分的依据与数据时点。
   - 不确定的数据明确标注"未获取到/建议核对官方原文"，**禁止虚构行情、财务数字与链接**。
   - 时间敏感信息注明数据日期/时点。

5. **交付**：输出 Markdown 研究报告，结尾附：
   - 数据口径与来源索引
   - 置信度与主要风险
   - 免责声明：本内容仅用于学习与量化研究，不构成投资建议；回测结果不代表未来收益。

## 注意
- 只读研究：不写文件、不改仓库（如需落盘报告由用户/主 Agent 决定）。
- 若任务适配财报解读类已启用技能，优先按该技能流程并保留来源核验链。
